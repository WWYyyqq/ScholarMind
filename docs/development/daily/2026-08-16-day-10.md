## 4. 准确性加固

### 4.1 参考文献列表检测

原规则只能识别：

- Section 明确为 References/Bibliography；
- Passage 一开始就是 `[数字] 作者 年份`。

真实 PDF chunk 可能以“上一条参考文献的尾部”开始，再包含 `[74]`、`[75]`。
新规则在一个 passage 中发现两个以上“编号 + 作者式起始”时，以
`reference_list` 原因拒绝。两个编号是保守阈值，不会把普通正文单个 `[12]`
引用当作参考文献页。

### 4.2 截断 Claim 阻断

Extractive Claim 现在必须以中英文终止标点结束。位于 chunk 尾部的半句话即使
与 Evidence 逐字匹配，也不能通过生成阶段进入报告。

修复后重跑同一真实问题：

- 状态仍为 success；
- 仍有 5 条完整 Claim 与 5 条页码 Citation；
- 参考文献标题不再进入报告；
- 末尾截断的 `caused the observed` Claim 不再进入报告。

## 5. 可重复运行工具

### 5.1 `scholarmind doctor`

新增项目 CLI：

```bash
.venv/bin/python -m scholarmind.cli doctor
```

它真实检查：

- PostgreSQL 是否可连接、语料与当前模型向量是否非空；
- Embedding 是否返回 1024 维有限数值；
- Rerank 是否返回完整分数并把相关证据排在无关证据前。

失败结果只包含检查代码和异常类型，不回显 DSN、密码或论文正文。真实结果为
`status=ready`。

### 5.2 Agent 启动脚本

新增 `scripts/start_scholarmind_agent.sh`：

- 只读取项目 `.env.postgres`；
- 为当前进程补全 Embedding 模型、维度、地址与本地 API Key；
- 检查项目 `.venv`；
- 以单 Worker 启动本地 LangGraph；
- 不修改系统环境变量和其他项目。

### 5.3 隐私安全 API 冒烟

新增 `scripts/smoke_scholarmind_api.py`。它执行真实研究请求，并验证：

- success 与 publication gate；
- Evidence/Claim/Citation 均非空；
- Citation 引用已返回的 Claim 和 Evidence；
- 每条 Citation 都有页码；
- counts 与实体数量一致。

输出只包含计数和布尔校验，不打印本地论文 Evidence。真实结果为 passed，5/5/5
且 Citation 链有效。
